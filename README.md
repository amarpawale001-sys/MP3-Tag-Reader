# MP3 Tag Reader and Editor in C

## Project Overview

MP3 Tag Reader and Editor is a C project used to read, display, and modify metadata stored in MP3 files. It allows users to view information such as song title, artist, album, year, and genre. The project works with MP3 metadata using file handling and provides options to view and edit tag information.

## Features

* **View Tags:** Displays metadata such as title, artist, album, year, and genre.
* **Edit Tags:** Allows users to modify supported MP3 metadata fields.
* **File Handling:** Reads and updates metadata directly in MP3 files.
* **Command-Line Arguments:** Accepts input filenames through command-line arguments.

## Technologies Used

* C Programming
* File Handling
* Structures and Pointers
* String Handling
* Command-Line Arguments

## Key Learnings

* Understanding MP3 metadata and ID3 tags.
* Performing file operations to read and modify metadata.
* Using structures and pointers to manage tag information.
* Handling command-line arguments and validating input files.
